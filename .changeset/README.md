# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in the changesets repository](https://github.com/changesets/changesets)

We have a quick list of common questions to get you started:

## How do I add a changeset?

Run `pnpm changeset` in the root of the repository. It will ask you:

1. Which packages have changed
2. What type of change it is (major, minor, patch)
3. A summary of the change

## What is a changeset?

A changeset is a piece of information about changes made in a branch or commit. It holds three bits of information:

- What packages need to be released
- What semver bump types the packages should receive
- A changelog entry for the released packages

## How do changesets get consumed?

When you run `pnpm version`, changesets will:

1. Find all changesets in the `.changeset` folder
2. Bump the versions of all packages mentioned in changesets
3. Update the CHANGELOG.md files for each package
4. Delete the consumed changeset files

When you run `pnpm release`, it will:

1. Build all packages
2. Publish updated packages to npm
